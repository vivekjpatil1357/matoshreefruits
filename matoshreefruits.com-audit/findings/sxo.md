# SXO (Search Experience Optimization) Audit: Matoshree Fruits

## 1. Executive Summary & Page-Type Mismatch
- **Target URL**: `https://www.matoshreefruits.com/hi` (with `/mr`, `/en` variants)
- **Primary Keyword Intent**: केला थोक (Banana wholesale), किसानों से सीधा केला सप्लाई (direct-from-farmer banana supply), banana wholesale supplier near me.
- **SERP Dominant Page Type**: Farmer-direct supplier pages, agricultural wholesale directories, B2B wholesale directories (IndiaMART, Justdial).
- **Target Page Type**: Single-page B2B business landing page with static sections (stock, gallery, contact).
- **Mismatch Severity**: **MEDIUM**. B2B buyers searching for direct-farm wholesale supply expect variety and grade details, daily availability, farm loading information, and bulk enquiry forms; the current page already provides the core conversion path but needs deeper stock detail.

## 2. User Stories
1. **Bulk Buyer / Trader (Consideration Stage)**: As a fruit wholesaler, I want to see today's live banana availability per quintal/box so that I can compare supply options before placing an order. *(Signal: High transactional intent on supply queries).*
2. **Local Farm Buyer (Decision Stage)**: As a regional distributor, I want exact farm/loading location details and direct contact numbers so I can arrange transport. *(Signal: "near me" and local geo-intent).*
3. **Farmer / Supplier (Awareness Stage)**: As a banana farmer, I want to know commission rates, payment terms, and daily unloading schedules so I can sell my produce here. *(Signal: Farmer-direct value proposition).*

## 3. Gap Analysis (SXO Gap Score: 58/100)
- **Page Type (8/15)**: Single-page layout can be strengthened with long-tail direct-farm availability and freshness signals.
- **Content Depth (7/15)**: Missing daily price ticker, crate/weight specifications, and variety breakdowns.
- **UX Signals (10/15)**: Clean mobile design with WhatsApp CTA, but lacks interactive stock calculators or live updates.
- **Schema (4/15)**: Zero structured data (missing LocalBusiness, Organization, Product).
- **Media (10/15)**: Gallery present, but lacks high-res grading videos and loading dock walkthroughs.
- **Authority (11/15)**: Mentions farmer-direct, but lacks APMC licenses, establishment years, or verified trader badges.
- **Freshness (8/10)**: Stock section exists, but frequency of updates is unclear to searchers.
